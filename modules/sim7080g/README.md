# SIM7080G Module

A plug-in expansion module for the [A0 base board](../../a0/README.md) based on the **SIMCom SIM7080G**.

## Overview

The SIM7080G provides **NB-IoT / LTE-M (Cat-M)** cellular connectivity plus **GNSS** positioning. Plug it into one of the A0 base board's expansion slots (**BUS1** or **BUS2**) to add a reliable cellular uplink for NB-IoT and LTE-M deployments.

## Key Features

- **Cellular**: NB-IoT and LTE-M (Cat-M) uplink
- **GNSS**: GPS/GLONASS/BeiDou/Galileo positioning
- **Interface**: connects to the ESP32-C6 over UART via the expansion bus
- **Power**: supplied from the expansion bus
