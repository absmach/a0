# E07-400M10S Module

A plug-in expansion module for the [A0 base board](../../a0/README.md) based on the **Ebyte E07-400M10S** sub-GHz radio module.

## Overview

The E07-400M10S is a compact sub-GHz (400 MHz) RF transceiver module with 10 dBm output. Plug it into one of the A0 base board's expansion slots (**BUS1** or **BUS2**) to add low-power, long-range sub-GHz connectivity for private sensor networks and IEEE 802.15.4-style links.

## Key Features

- **Sub-GHz radio**: 400 MHz band, 10 dBm output power
- **Low power**: suited to battery-powered operation
- **Interface**: SPI / UART over the expansion bus
- **Power**: supplied from the expansion bus
