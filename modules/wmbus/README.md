# WMBUS Module

A plug-in expansion module for the [A0 base board](../../a0/README.md) implementing **Wireless M-Bus (EN 13757-4)**.

## Overview

The WMBUS module adds a Wireless M-Bus radio for reading utility meters (heat, water, gas, electricity). Plug it into one of the A0 base board's expansion slots (**BUS1** or **BUS2**) to enable smart metering deployments.

## Key Features

- **Wireless M-Bus (EN 13757-4)** communication
- Connects to the ESP32-C6 over the expansion bus
- Powered from the expansion bus
